# Personal Expense Tracker

A Level 2 Hackathon project (Fundamentals of Web Development) built with HTML, CSS and vanilla JavaScript.

## Features
- Add, edit and delete income / expense transactions
- Manage categories
- Search and filter by description, category, type and date range
- Live totals: income, expenses, balance
- Monthly summary table and expense chart (by category / month) drawn with the Canvas API
- Data persisted in browser Local Storage

## Run
Open `index.html` in any modern browser. No installation or server required.

## Files
`index.html` – structure | `style.css` – styling | `script.js` – logic, storage and chart
